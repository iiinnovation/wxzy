## Service API

```text
generate_daily_plan(...)
get_or_create_today_plan(...)
adjust_today_budget(...)
GENERATION_VERSION = "daily-plan-v1"
```

Rules:
- minute budget from LearningProfile.daily_minutes (or temporary adjusted budget)
- fill order: due/overdue -> weak/repair -> new (if not paused) -> weekly mixed
- response_ms history median estimates task duration; cold start uses 45/90/60s defaults
- backlog or 7d forecast over budget sets `new_cards_paused` and blocks new cards
- items reference enrollment_id/card_id; reason_code required
- budget reduction preserves pending items (PLAN-006)
